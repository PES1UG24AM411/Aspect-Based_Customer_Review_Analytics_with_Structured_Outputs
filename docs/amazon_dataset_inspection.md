# Dataset Inspection

## Overview

The original e-commerce customer review dataset was inspected
before preprocessing.

## Recorded Baseline

| Metric | Result |
|---|---:|
| Original records | 1,728 |
| Columns | 10 |
| Unique ASINs | 452 |
| Exact duplicate full rows | 0 |

## Inspection Notes

- The dataset contains customer reviews associated with product ASINs.
- Dataset inspection was completed before the preprocessing stage.
- Language identification, review cleaning, duplicate handling,
  and partitioning are performed by the preprocessing pipeline.

## Data Availability

The original dataset is maintained locally and is not included
in the public source-code repository.
